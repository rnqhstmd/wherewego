색·폰트 토큰(WGColor/WGFont)은 100% 유지하고, 레이아웃 문법만 인스타그램으로 교체한 제안입니다. 인스타의 파랑 자리는 전부 테라코타(cta #C4622D)가 대신합니다. GP-1(그룹 대표 이미지·프사·콜라주)이 모든 화면의 시각 중심이 됩니다.

1. 카드 → 플랫 행흰 카드+테두리+그림자를 버리고, 인스타식 풀-블리드 행(아바타 56pt + 2줄 텍스트 + 여백 분리). 구분선도 없앰 — 여백이 곧 구분.
2. 큰 제목 → 경량 상단바ScreenHeader(고운바탕 큰 제목) 대신 인스타식 48pt 상단바: 좌측 Pretendard Bold 21 타이틀 + 우측 액션 아이콘. 고운바탕(emo)은 온보딩·빈 화면 등 브랜드 모먼트에만 남김.
3. 프사가 모든 행의 주인공GP-1 아바타/콜라주를 행 좌측 고정 슬롯으로. 그룹·채팅·알림·프로필 모든 행이 같은 아바타 문법을 공유.
4. 채팅 = 인스타 DM 문법수신=흰 필(테두리)+프사 하단정렬, 발신=cta 단색 필(꼬리 없는 라운드 20). 입력바는 둥근 필 + 필 안쪽 원형 전송 버튼.
5. 내정보 = 인스타 프로필큰 아바타(84pt, 카메라 배지) + 그룹·핀·함께한 날 통계 + 풀폭 라이트 버튼 2개. 설정은 아이콘+라벨 플랫 리스트.
