# PRD: IG-2 인스타그램 리디자인 — 채팅방·프로필·알림

> 2026-06-12 승인. SSOT: context/ig-redesign-plan.md (목업 v4 = context/app-redesign-instagram.html)

## 1. 배경

IG-1(PR #124, develop 머지)로 셸이 인스타 문법으로 전환 완료 — 경량 상단바(`InstaNavBar`)·4탭바(내정보=프사 원형)·그룹/채팅 목록 플랫화. IG-2는 콘텐츠 화면 3종(채팅방·내정보·알림)을 같은 문법으로 교체하고, 합의된 UX 단순화(채팅방 진입=무조건 최신)와 이를 받치는 백엔드 소규모 확장을 포함한다. WGColor/WGFont 토큰 100% 유지, 인스타의 파랑 자리는 전부 테라코타 cta(`#C4622D`).

## 2. 목표

- 채팅방·내정보·알림이 IG-1 셸과 일관된 인스타 문법을 갖춘다 (Mac 시각 QA는 DoD-B 별도).
- 채팅방 진입 로직 단순화로 앵커 관련 상태·테스트 복잡도를 제거한다.
- 알림 → 지도 핀까지 한 번의 탭으로 이어지는 딥링크 경로를 신설한다.

## 3. 요구사항

### FR-1 채팅방 인스타 DM화 [Must]
- 버블: 수신 = 흰 필 + 헤어라인 + 좌하단 꼬리(radius 6) / 발신 = cta 단색 필 + 라운드 20, 흰 텍스트.
- 프사: 수신 28pt, 버블 하단 정렬. 연속 메시지 그루핑 규칙 보존.
- 입력바: 둥근 필 + 필 안 원형 전송 버튼만(카메라 없음). 빈 입력 시 전송 비활성.
- 헤더: 그룹 아바타(`GroupAvatarView`) + 그룹명 + 멤버 수, `InstaNavBar` 문법.
- REEL_LINK: 인스타 DM 게시물 공유 카드 문법. 3상태 버튼 기능 회귀 없음.

### FR-2 채팅방 진입 단순화 [Must]
- 진입 시 무조건 최신 메시지로 스크롤. `initialUnreadAnchorId`·`serverLastReadId` 앵커 용도·`didInitialScroll` 앵커 분기·진입 "새 메시지" 필 제거(죽은 코드 삭제, 주석 처리 금지).
- 유지: 위로 읽는 중 도착 배너, 채팅 목록 미읽음(백엔드 읽음 테이블·unreadCount 무변경).
- 관련 단위 테스트 정리(reconcileLatest 플래키 재점검 포함).

### FR-3 내정보 프로필화 [Must]
- 프로필 헤더: 아바타 84pt + 우하단 카메라 배지(GP-1 원형 크롭 직행) + 닉네임 + 통계 2종(그룹 수 · 등록한 핀 수).
  - 등록한 핀 수 = 내가 등록한 활성 핀(soft-delete 제외) 전 그룹 합산. 그룹 수 = 기존 그룹 목록 기반.
- 버튼: 프로필 편집 단일 풀폭 라이트 버튼 (프로필 공유 기능·버튼 없음 — Q2 확정).
- 프로필 편집 화면 신설: 프사 변경(원형 크롭 플로우 재사용) + 닉네임 수정을 한 화면에서 — 인스타 프로필 편집 문법 (Q5 확정).
- 설정 플랫 리스트: 알림 설정 · 내 그룹 관리 · 약관 · 로그아웃 · 계정 삭제.
- 알림 설정(신규): `openSettingsURLString` 시스템 설정 딥링크. 유형별 on/off는 비범위.

### FR-4 알림 탭 피드화 + 핀 딥링크 [Must]
- 행: 행위자 프사(`AvatarView`, 이니셜 폴백) + "누가 무엇을" 인라인 Bold + 상대시각 + 우측 36pt 썸네일(대표 핀 사진, 없으면 생략 — Q3 확정). 오늘/이번 주 섹션.
- 핀 딥링크: 알림 탭 → 지도탭 전환 → 해당 그룹 맵 전환 → 핀 1개 = 카메라 이동 + 말풍선 자동 오픈 / N개 = 전체 fitBounds(말풍선 없음) (Q4 확정, `.reelFocus` 선례).
- 엣지: 삭제된 핀 → 이동 없이 토스트("삭제된 장소예요"). 탈퇴/삭제 그룹 → 전환 불가 안내.

### FR-5 백엔드 소규모 확장 [Must]
- `GET /users/me` 응답에 `pinCount` 확장 (Q1 확정).
- 알림 목록 응답 확장: 행위자 유효 프사 URL(GP-1 resolver 재사용) + 딥링크용 `groupId` + 대표 `pinId` + 대표 핀 사진 썸네일 URL (현재 목록 응답에 모두 부재 — 코드 확인 완료).

### [Should]
- FR-2 단순화에 따른 죽은 코드(앵커 관련 상태·분기) 완전 삭제.

## 4. 비범위

토큰 변경 · 유형별 알림 on/off · REEL_LINK 썸네일(GC-3) · 웹 프론트 · 채팅 사진 전송 · 프로필 공유 · Mac 시각 QA/실기기(DoD-B).

## 5. 수용 기준

1. 채팅방 버블·입력바·헤더가 목업 v4 문법과 일치, REEL_LINK 3상태 회귀 없음.
2. 진입 시 항상 최신 메시지 표시, 앵커 상태 코드 삭제, 도착 배너·목록 미읽음 정상.
3. 내정보: 헤더(아바타+통계 2종)·편집 버튼·설정 리스트 표시, 각 항목 기존 플로우 정상 연결, 프로필 편집 화면에서 프사+닉네임 수정 가능.
4. 활성 핀 알림 탭 → 지도탭·그룹 전환·카메라·말풍선(1개)/fitBounds(N개)가 한 탭에 완료.
5. 백엔드: 알림 목록 프사 URL·groupId·pinId·썸네일 URL, me pinCount 제공 (compileJava+compileTestJava+관련 테스트 green).
6. iOS CI(GitHub Actions) green.
