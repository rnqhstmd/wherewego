# PRD: iOS IA 재설계 — 내비 골격

## 배경
현재 iOS는 하단 3탭(지도·채팅·어디갈까) + 상단(그룹칩·알림·내정보), 지도는 단일 레벨(활성 그룹 1개). 사용자가 IA를 재설계 — 하단 4탭(지도·DM·알림·내정보) 전역 + 지도 탭만 2레벨(그룹 목록↔그룹 지도). 이 단계는 그 골격(셸·라우팅)만 세우고, 각 탭의 내용은 같은 브랜치 후속 단계로 잇는다.

## 요구사항
### Must
- FR-1 하단 4탭(지도·DM·알림·내정보). 채팅→DM 변경, 어디갈까는 하단바 제거(지도 좌하단 FAB로), 알림·내정보는 상단→하단탭 이동
- FR-2 지도 탭 2레벨: 레벨0=그룹 목록, 레벨1=그룹 지도. 마지막 본 그룹 기억 → 다른 탭 갔다 와도 그 그룹 지도로 직행
- FR-3 지도 탭 더블탭 → 그룹 목록(레벨0)
- FR-4 그룹 지도 상단: 그룹 전환 버튼 + 뒤로가기(→목록) + ⋯(그룹관리 진입점만, 내용은 D)
- FR-5 그룹 컨텍스트 전역 상태: 그룹 목록 + 현재 그룹 + 마지막 그룹. GroupAPI.listMyGroups 소비
- FR-6 어디갈까(룰렛) 지도 좌하단 FAB + 필터/범례 상단 이동

### Should
- FR-7 그룹 전환 시 "로딩 척" 진입점만(실제 최적화는 C단계)

### 비범위 (후속, 같은 브랜치)
- DM 탭 내용(#105 목록·읽음 소비), 알림 상세·내정보 축소(D), ⋯ 그룹관리 내용(D), IC-2 초대코드, 맵 로딩 최적화 실구현(C)

## 수용 기준
- AC-1 하단 4탭(지도·DM·알림·내정보) 표시, 어디갈까 탭 제거
- AC-2 지도 탭 그룹 목록↔그룹 지도 2레벨 전환
- AC-3 마지막 그룹 기억 → 탭 복귀 시 지도 직행
- AC-4 지도 탭 더블탭 → 그룹 목록
- AC-5 그룹 지도 상단 그룹 전환·뒤로·⋯ 노출
- AC-6 그룹 컨텍스트(목록·현재·마지막) 동작 + listMyGroups 소비
- AC-7 어디갈까 좌하단 FAB, 필터/범례 상단
- AC-8 DM/알림/내정보 탭 진입 가능(내용은 기존/플레이스홀더 — 골격만)

## 설계서에서 확정할 것
1. 그룹 목록(레벨0) = 신규 화면 vs GroupSwitcherSheet 재활용
2. 그룹 컨텍스트 상태 모델(현 GroupContext 확장 범위)
3. 탭 더블탭 감지 메커니즘
4. DM/알림/내정보 탭 골격 처리(기존 유지 vs 플레이스홀더)
