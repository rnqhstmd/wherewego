# PRD: iOS IA 재설계 — C (맵/필터 정리)

> IA 재설계 묶음 브랜치 feat/ios-ia-redesign, 골격 A(PR #106) 위 누적. 마스터 문서=roadmap.md.
> 스코프 결정(2026-06-08): 맵 1회 로딩은 **B안(연출만·안전)** — 구조 변경 없이 그룹 전환 줌 연출만.

## 배경
IA 재설계 골격(A)에서 지도 화면 **좌하단**에 어디가지(룰렛) FAB가 추가되며 기존 좌하단 필터(▽)/범례(!) 버튼과 자리가 충돌(어디가지 FAB 아래 적층). C 단계는 (1) 필터/범례를 **상단으로 이동**해 좌하단을 어디가지 FAB 전용으로 정리하고, (2) 그룹 전환 시 Mapbox 전면 재로딩 인상 대신 **줌아웃→줌인 연출 + 핀 교체**로 매끄럽게("로딩 척") 만든다.

## 요구사항

### Must
- **FR-C1 필터/범례 상단 이동**: 좌하단 `TagLegendButton`(!)·`TagFilterButton`(▽)을 지도 **상단**으로. 좌하단은 어디가지 FAB 단독. 팝업(범례 안내/필터 체크박스)은 상단 배치에 맞게 **아래 방향**으로 펼침(현재 위로). 범례·필터 상호배타(동시 표시 금지)·바깥 탭 닫힘 유지.
- **FR-C2 상단 레이아웃 공존**: 기존 그룹 오버레이(뒤로·그룹명·⋯) + 릴스 포커스 배너(MainTabView top overlay)와 **겹치지 않게** 배치.
- **FR-C3 그룹 전환(레벨1) 줌 연출**: 상단 그룹전환 버튼으로 다른 그룹 전환 시(switchGroup→switchTo, 이미 MapView 유지·재로딩 없음) **줌아웃 → (가능 시) 내 위치 줌인** 연출 후 **핀만 새 그룹으로 교체**. 전면 로딩 스피너 노출 최소화(연출로 가림).
- **FR-C4 회귀 없음**: 필터 동작(activeFilters 토글·적용 중 주황 점·빈 Set=마커 0)·기존 지도 기능(인라인 추가/딥링크 flyTo/방문감지/말풍선) 무손상.

### Could
- **FR-C5 줌인 대상 보강**: 위치 권한 거부/좌표 실패 시 줌인 대상을 새 그룹 핀들의 bounds(fitBounds)로 대체.

### 비범위 (B안 — 후속 분리)
- **Mapbox 진짜 1회 로딩**(목록 레벨0↔지도 레벨1 상시 마운트 구조 변경, enterGroup→switchTo 통합) — 리스크/규모로 이번 제외. 목록→그룹 선택 시 재마운트(재로딩)는 수용. 후속 단계로 분리 가능.
- DM 그룹별 목록(#105 소비), 알림 상세·내정보 축소(D), ⋯ 그룹관리 내용(D), IC-2 초대코드.

## 수용 기준
- **AC-C1** 지도 상단에 필터(▽)·범례(!) 노출, 좌하단엔 어디가지 FAB만 남음.
- **AC-C2** 필터/범례 탭 → 팝업이 **아래로** 펼쳐지고, 그룹 오버레이(뒤로·그룹명·⋯)·릴스 배너와 겹치지 않음.
- **AC-C3** 범례·필터 상호배타 + 바깥 탭 닫힘 + 필터 토글/주황 점 동작이 이동 전과 동일.
- **AC-C4** 그룹 전환 시 전면 로딩 스피너 없이 줌아웃→줌인 연출 + 핀이 새 그룹으로 교체됨.
- **AC-C5** 위 변경이 핀 추가(인라인)·딥링크 flyTo·방문감지·말풍선 등 기존 지도 기능을 깨지 않음.

## 설계서에서 확정할 것
1. 필터/범례 상단 배치 형태(그룹 오버레이 행 우측 합류 vs 아래 2번째 행) + 팝업 아래펼침 offset.
2. switchTo 줌아웃→줌인 카메라 시퀀스(2단 flyTo 타이밍, B2 cameraCommand 1회 소비 계약 내 충돌 회피).
