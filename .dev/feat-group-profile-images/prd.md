# PRD: 그룹 대표 이미지 · 프로필 사진 (GP-1)

> 2026-06-11 확정 (사용자 승인). 브랜치 feat/group-profile-images, base develop.

## 1. 배경

현재 그룹과 사용자 모두 시각적 식별 수단이 없다. 그룹 목록은 그룹명+멤버 수(텍스트)만, 채팅 탭은 플레이스홀더 원형만, 채팅 상세는 닉네임 이니셜 원형만 노출된다. 그룹 다중화(GM-1) 이후 "이 그룹에 누가 있었지"를 인지하기 어렵다.

활용 가능한 기존 자산:
- `UserModel.profileImageUrl` — 카카오 로그인 시 카카오 프사 자동 수집 (Apple은 미제공 → null)
- S3 사진 인프라(`S3PinPhotoStorage`): 업로드 + webp 썸네일 + immutable 캐시 — 패턴 재사용
- iOS `Features/Photo`: 사진 선택 + 정사각 크롭 UI — 원형 마스크 변형 기반

## 2. 요구사항

### Must

| ID | 요구사항 |
|----|----------|
| FR-1 | **그룹 생성 시 대표 이미지 지정** — 생성 화면에서 사진 선택 → 원형 크롭 UI → 업로드. 지정은 선택사항 |
| FR-2 | **그룹 대표 이미지 수정·제거** — 그룹 관리 화면에서 활성 멤버 누구나 변경/제거 가능(그룹명 수정과 동일 권한). 제거 시 기본 표현(콜라주)으로 복귀 |
| FR-3 | **내 프로필 사진 지정·제거** — 내정보 탭에서 사진 선택 → 원형 크롭 UI → 업로드. 제거 시 이니셜 원형으로 복귀 |
| FR-4 | **그룹 목록: 썸네일 + 멤버 프사 전원 일렬 나열** — 각 행에 ① 그룹 대표 이미지 원형 썸네일(미지정 시 멤버 프사 콜라주) ② 활성 멤버 전원의 프사를 가입순 가로 일렬 나열. 프사 없는 멤버는 이니셜 원형 폴백 |
| FR-5 | **채팅 탭 방 썸네일** — 채팅방 목록 각 행 썸네일 = 그룹 대표 이미지(미지정 시 콜라주) |
| FR-6 | **채팅 상세 발신자 프사** — 타인 메시지의 아바타 자리에 발신자 프사. 없으면 현행 이니셜 원형 유지. 내 메시지에는 미표시(카톡식) |
| FR-7 | **카카오 프로필 동기화 전면 중단** — 가입 시 1회만 닉네임·프사를 수집하고, 재로그인 시 `updateProfile` 갱신을 제거(사용자 지정 프사·닉네임 보존) |
| FR-8 | **그룹 정원 10→8 축소** — `MAX_GROUP_MEMBERS=8`. 기존 9~10명 그룹은 유지(강제 퇴장 없음)하되 신규 가입만 차단. 초대 미리보기(IC-1)·정원초과 응답 동일 적용 |

## 3. 정책 (BR)

- **BR-1 크롭은 클라이언트 책임**: iOS가 원형 크롭 UI로 영역을 지정하고 정사각형으로 잘라 업로드. 서버는 정사각 저장만, 원형 표현은 클라가 `clipShape(Circle())` 렌더링
- **BR-2 업로드 권한**: 그룹 이미지 = 해당 그룹 활성 멤버만. 프로필 사진 = 본인만
- **BR-3 저장**: S3 핀 사진 패턴 재사용 — 크롭된 정사각 1장 + webp 썸네일(목록용). 키: `groups/{groupId}/avatar/{uuid}.jpg`, `users/{userId}/avatar/{uuid}.jpg`. 교체/제거 시 이전 객체 best-effort 삭제
- **BR-4 검증**: 핀 사진과 동일한 크기·형식 제한 재사용(서버 디코드 검증)
- **BR-5 기본 표현(콜라주)**: 그룹 이미지 미지정 시 가입순 최대 4명의 멤버 프사를 카톡식 콜라주(1=단일 원, 2=대각, 3=삼각, 4=2×2)로 합성. 프사 없는 멤버는 이니셜 셀. 합성은 클라이언트 렌더링(서버 합성 없음)
- **BR-6 탈퇴 멤버**: 멤버 프사 나열·콜라주·그룹원 목록에 미포함(활성 멤버 기준). 채팅 상세에서 발신자 NULL은 "(알 수 없음)" 이니셜 원형
- **BR-7 카카오 프사 초기값**: 가입 시 수집된 카카오 프사가 있으면 그것이 초기 프사(별도 지정 전까지 사용)

## 4. 수용 기준 (AC)

1. 그룹 생성 시 사진을 선택·원형 크롭하면 목록/채팅탭 썸네일에 반영. 사진 없이 생성하면 멤버 프사 콜라주가 보인다
2. 비방장 포함 활성 멤버 누구나 그룹 이미지를 변경·제거할 수 있고, 재조회 시 다른 멤버 화면에도 반영. 비멤버 시도는 403
3. 내정보에서 프사 지정·제거 시 그룹 목록 나열·콜라주·그룹원 목록·채팅 상세 아바타에 반영
4. 프사를 직접 지정한 사용자는 카카오 재로그인 후에도 지정 프사 유지
5. 그룹 목록 각 행에 활성 멤버 전원의 프사가 가입순 일렬로 노출, 프사 없는 멤버는 이니셜 폴백
6. 9명 그룹(기존)에 신규 가입 시도 → `GROUP_CAPACITY_EXCEEDED`. 7명 그룹 가입은 성공(정원 8)
7. 채팅 상세에서 타인 메시지에 발신자 프사, 없으면 이니셜 원형 유지
8. 이미지 로드 실패 시 모든 지점에서 기본 표현 폴백(깨진 이미지 노출 없음)
9. 백엔드 compileJava+compileTestJava·관련 테스트 통과, iOS CI green

## 5. 범위 제외

- 웹 프론트엔드 반영(앱 게시 시 종료 예정)
- 이미지 모더레이션
- 채팅 메시지 내 사진 전송

## 6. Q&A 확정 이력

- Q1 그룹 이미지 미지정 기본 표현 → 멤버 프사 콜라주(카톡식, 가입순 최대 4명, 프사 없는 멤버는 이니셜 셀)
- Q2 카카오 프사 동기화 → 전면 중단(가입 시 1회 수집, 재로그인 갱신 제거 — 닉네임 포함)
- Q3 그룹 목록 멤버 프사 → 전원 가입순 일렬 나열 + 그룹 정원 10→8 축소(기존 초과 그룹 유지, 신규 가입만 차단)
- Q4 이미지 제거(기본 표현 복귀) → 포함(그룹·프사 모두)
