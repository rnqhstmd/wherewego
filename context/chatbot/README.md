# chatbot

카카오톡 Skill Webhook을 받아 인스타 릴스 링크를 자동 핀으로 변환하는 인터페이스 레이어.

## 배경

데이트 장소를 정할 때 사용자는 이미 카카오톡에서 인스타 릴스를 공유한다. 이 자연스러운 흐름에 끼어들어 "공유 한 번으로 핀 등록"을 실현하는 것이 본 도메인의 목적이다. 카카오 i 오픈빌더의 Skill Webhook으로 Spring Boot REST API에 이벤트를 받고, 리스트 카드/말풍선으로 사용자에게 응답한다.

## 안 하면 어떻게 되는가

- 사용자가 웹에서 일일이 장소를 검색/입력해야 함 → 핵심 가치(편리함) 소실
- 인스타 릴스 → 지도 핀의 즉시성이 사라져 데이트 지도 누적이 더뎌짐

## 사용자와 규모

- 사용자: MVP ~100명, 그룹당 1~2명이 챗봇 사용
- 트래픽 추정: 인당 주 5~10건 링크 공유 → 일 평균 ~100건 Webhook 호출

## 성공 기준

- Webhook 응답 SLA ≤ 5초 (카카오 i 오픈빌더 타임아웃 한계 내)
- 5자리 연동 코드 매칭 성공률 ≥ 99%
- 장소명 추출 → 핀 자동 등록 성공률 ≥ 70% (실패는 사용자 입력으로 폴백)
