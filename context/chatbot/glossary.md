# chatbot 용어 사전

| 용어 | 설명 |
|------|------|
| Skill Webhook | 카카오 i 오픈빌더가 백엔드 REST API로 보내는 챗봇 이벤트 호출. 5초 응답 SLA |
| botUserKey | 카카오톡 챗봇이 사용자별로 발급하는 식별자. 웹 user_id와 5자리 코드로 매칭 |
| 5자리 연동 코드 | 웹에서 발급되는 일회성 난수. TTL 10분. 충돌 시 재생성. 활성 코드 1개/유저 |
| 매핑 저장 | `bot_user_mappings(bot_user_key, user_id, linked_at)`. 영구 저장 |
| 리스트 카드 | 카카오톡 챗봇 응답 컴포넌트. 최대 5개 항목 |
| 콜백 메시지 | 5초 SLA 초과 비동기 작업 결과를 사용자에게 푸시하는 카카오 i 오픈빌더 기능 |
| 동기/비동기 분기 | Kakao Local까지 동기, Google 폴백은 비동기 |
| 폴백 메시지 | 장소명 추출 실패 시 "어느 곳인가요?" 텍스트로 사용자 입력 유도 |
