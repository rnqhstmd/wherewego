§ 01 — 편집장의 말

지도는 결국 누구와 보느냐의 문제다.

연인이든 친구 셋이든 가족이든, "거기 가보고 싶다"와 "거기 같이 갔었지"의 거리는 한 줄짜리 메모 안에 다 들어간다. 우리가 만든 것은 그 한 줄들을 한 장의 지도 위에 오래도록 쌓아두는 작은 의식이다.

카카오톡 대화창에서 인스타 릴스를 챗봇에 흘리면, 2초 안에 쓴 한 줄이 그 핀의 메모가 된다. 편집은 언제든 — 손으로 쓴 메모가 자동 메모보다 항상 위에 있다.

"여기 디저트 진짜 맛있대"
— 그 한 줄이 핀의 메모가 됩니다.

§ 04 — 세 가지 차별

지도에 머무는 시간을
의식처럼.

A · Globe

3D 지구본 위의 둘만의 핀

Mapbox 3D 글로브에서 줌 아웃하면 핀들은 지구 표면을 따라 휜다. 도쿄와 제주가 같은 시야에 들어오는 순간이 있다.

B · Roulette

오늘 어디 갈까? — 룰렛

도보 1km, 대중교통 5km, 드라이브 10km. PLACE 핀 중 한 곳을 무작위로 뽑아 결정 부담을 덜어준다.

C · Group

둘이 시작, 더 늘어나도 좋다

MVP는 2인 커플. 스키마는 N:M 그룹 멤버 구조로 — 친구 셋, 가족 다섯도 같은 지도를 공유하도록 처음부터 설계했다.

§ 06 — Eight screens

여덟 개의 화면이 한 권의 노트처럼.

01 · MAP

둘만의 지도

3D 글로브, 파스텔 마커, 상단 검색·태그 필터, 하단 룰렛.

 02 · PIN

핀 상세 (AMOU)

장소·메모·릴스·태그 변경. 등록자와 다녀온 일자.

 03 · ADD

장소 검색 + 추가

카카오 로컬·Google Places 결과와 태그 선택.

 04 · TAG

PLACE / MEMORY 컬렉션

탭, 그리드, 정렬, 비율 통계.

 05 · MEMO

메모 편집 · 2초 룰

AUTO/MANUAL 출처와 우선순위 정책 컨텍스트.

 06 · GROUP

그룹 · 초대 링크

멤버 카드와 24h TTL 초대 토큰.

 07 · BOT

챗봇 연동 코드

6자리 코드, 10분 카운트다운, 채널 친구추가.

 08 · INDEX

이 컬렉션 — 콜로폰

도메인 매트릭스와 발행 정보.
§ 07 — Domain matrix

이 호의 색인 — 아홉 개 도메인.

A auth 카카오 OAuth2 + JWT (Access 1h · Refresh 14d, SHA-256 hash 저장). 별도 회원가입 없이 카카오 한 번으로 진입. ~100 users / phase 1
B group User N:M Group · MVP는 2인 강제 (Partial UNIQUE INDEX). 탈퇴 시 핀은 그룹에 잔류, 추억 보존 우선. ~50 groups / mvp
C chatbot 카카오 i 오픈빌더 Skill Webhook. 6자리 연동 코드 TTL 10분. SLA 5초. ~100 webhooks / day
D place 인스타 og: 메타 파싱 → 카카오 로컬 → Google Places 폴백. ContentParser 인터페이스로 멀티 플랫폼 확장 가능. ~70% 추출률
E pin 그룹 단위 핀 CRUD. UNIQUE(group_id, instagram_url)로 챗봇 중복 차단. visited 폐기 — 의미는 tag로. ~50 pins / group
F memo 2초 룰 (링크 직후 텍스트). memo_source AUTO/MANUAL. 수동이 자동을 항상 이긴다. 95% 매칭 목표
G tag — MVP 핵심 PLACE (파란 동그라미) / MEMORY (핑크 하트) 두 종. 핀 등록 경로별 기본값 + 상세에서 토글. PLACE 70 · MEMORY 30
H map Mapbox GL JS 3D globe. 파스텔 마커, AMOU 정보창 (장소+메모+릴스), 커스텀 검색 드롭다운. ~50–100 marker / view
I recommendation 위치 기반 룰렛. 1km · 5km · 10km. Haversine 거리. 후보 0건 시 다음 범위로 확장 제안. ≤ 1.5s 응답
