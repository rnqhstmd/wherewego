# auth

카카오 OAuth2 기반 개인 사용자 인증.

## 배경

서비스의 모든 데이터(핀, 메모, 태그, 그룹 멤버십)는 인증된 사용자 단위로 격리되어야 한다. 별도 회원가입 절차 없이 카카오 계정으로 바로 진입할 수 있도록 OAuth2 로그인만 제공한다. 챗봇이 카카오톡 기반이므로 동일 카카오 계정으로 챗봇과 웹을 연결하는 것이 자연스러운 UX다.

## 안 하면 어떻게 되는가

- 사용자 식별 불가 → 핀 데이터를 누가 등록했는지 알 수 없어 그룹 공유/격리 불가
- 챗봇 ↔ 웹 사용자 매칭 불가 → 6자리 연동 코드 기능 자체가 성립 안 됨

## 사용자와 규모

- MVP 초기 베타: ~100명 (커플 ~50쌍)
- 모두 카카오 계정 보유 가정 (한국 사용자 기준)

## 성공 기준

- 카카오 OAuth2 로그인 성공률 ≥ 99%
- 로그인 후 첫 화면 도달까지 ≤ 3초
