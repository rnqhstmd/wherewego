# Phase 11 — 우리 기록 (마이페이지)

## 개요

마이페이지에 **"우리 기록"** 섹션을 추가한다.
커플이 함께 저장한 모든 핀을 월별 타임라인으로 조회하며,
탭으로 추억/위시를 구분하고 카드를 탭하면 지도의 해당 핀 팝업으로 이동한다.

---

## 화면 구조

```
마이페이지
└── 우리 기록
    ├── [추억] [위시] [전체]   ← 상단 필터 탭
    └── 월별 타임라인
        ├── 2026년 5월 · 3곳
        │   ├── 카드
        │   ├── 카드
        │   └── 카드
        └── 2026년 4월 · 5곳
            └── ...
```

---

## 탭 정의

| 탭 | 포함 태그 | 의미 |
|----|-----------|------|
| 추억 | MEMORY | 실제 다녀온 곳 |
| 위시 | WISH, REEL | 가고 싶은 곳 |
| 전체 | 전체 | 모아보기 |

---

## 카드 사양

```
┌─────────────────────────────────────────┐
│  온량                      2026.05.20   │
│  서울 송파구 백제고분로43길               │
│  "우리가 처음 만난 곳"                   │
│  written by 구본승           [추억 ●]   │
└─────────────────────────────────────────┘
```

| 요소 | 설명 |
|------|------|
| 장소명 | 굵게, 메인 정보 |
| 주소 | 회색, 작게 |
| 메모 | 첫 줄만 이탤릭 표시. 없으면 생략 (카드 높이 축소) |
| written by | `memoUpdatedBy`가 등록자와 다르면 수정자 닉네임 표시 |
| 날짜 | `createdAt` YYYY.MM.DD |
| 태그 배지 | MEMORY: 채워진 핑크 ● / WISH: 아웃라인 ♡ / REEL: 연보라 인스타 아이콘 |

---

## 상호작용

- **카드 탭** → 지도 화면으로 이동 + 해당 핀 `flyTo` + `PinPopup` 자동 오픈
- **월 헤더** → 접기/펼치기 (선택 구현)
- **탭 전환** → 클라이언트 필터링 (API 재호출 없음, 전체 목록 1회 fetch)

---

## 구현 범위

### 프론트엔드

| 작업 | 파일 |
|------|------|
| 우리 기록 페이지 | `app/mypage/records/page.tsx` (신규) |
| 월별 타임라인 컴포넌트 | `_components/RecordTimeline.tsx` (신규) |
| 핀 기록 카드 컴포넌트 | `_components/RecordCard.tsx` (신규) |
| 탭 필터 | `RecordTimeline` 내부 상태 |
| 마이페이지 진입 링크 | `app/mypage/page.tsx` — "우리 기록" 메뉴 항목 추가 |
| 지도 이동 연결 | 카드 탭 시 `/map?pinId={id}` 라우팅 또는 상태 공유 |

### 백엔드

- 기존 `GET /api/v1/groups/{groupId}/pins` (전체 핀 목록) 재사용
- 정렬: `createdAt DESC` (기존 동작 확인 필요)
- 페이지네이션: 첫 단계는 전체 로드, 핀 수 증가 시 커서 페이지네이션 추가 고려

### 데이터 요구사항

- `PinSummaryResponse`에 `memoUpdatedBy` / `memoUpdatedByNickname` 포함 (Phase 10 이전 작업에서 완료)
- 추가 API 변경 없음

---

## UX 고려사항

- **메모 없는 카드**: 장소명 + 주소만 표시, compact 높이
- **삭제된 핀**: 취소선 + "삭제됨" 배지 (알림함과 동일 처리)
- **월별 핀 수**: `2026년 5월 · 3곳` 형식으로 밀도 표시
- **빈 상태**: 탭별 "아직 저장한 장소가 없어요" 안내 문구
