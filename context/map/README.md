# map

Mapbox 기반 글로벌 3D 지도와 핀 UI 렌더링 도메인.

## 배경

서비스의 시각적 핵심은 "3D 지구본 위에 우리만의 핀이 박힌 글로벌 지도"다. Mapbox GL JS의 무료 50k loads/월 한도 내에서 3D 지구본 모드, 감성 마커, AMOU 스타일 정보창, 커스텀 검색 UI를 구현한다. 백엔드 API는 데이터 소스이고, 본 도메인은 모두 프론트엔드(Next.js)에서 다룬다.

## 안 하면 어떻게 되는가

- 사용자가 핀을 시각적으로 확인/탐색할 수 없음 → 서비스 사용 가치 소실
- 3D 지구본/AMOU 스타일이 없으면 경쟁 지도 서비스 대비 차별점이 사라짐

## 사용자와 규모

- ~100명 × 일 평균 5회 접속 = 일 ~500 loads (월 ~15k loads, Mapbox 무료 한도 내)
- 그룹 평균 50핀 → 동시 렌더링 약 50~100개 마커

## 성공 기준

- 3D 지구본 모드 60fps 유지 (저사양 모바일에서 30fps 이상)
- 검색 UI → 핀 추가까지 ≤ 3 클릭
- 마커 1개 클릭 → 정보창 표시 ≤ 200ms
