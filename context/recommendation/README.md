# recommendation

위치 기반 랜덤 추천("오늘 어디 갈까?" 룰렛) 도메인.

## 배경

데이트 약속을 잡을 때 "어디 갈까?"라는 결정 부담을 줄이기 위해, 사용자 현재 위치 기준 반경 내 핀 중 랜덤 1곳을 추천한다. 도보(1km), 대중교통(5km), 드라이브(10km) 세 가지 거리 범위를 제공한다.

PRD 원문은 "미방문 핀 중 랜덤"이었으나 `visited` 기능이 제거되면서 후보 선정 기준이 변경됐다. MVP에서는 **PLACE 태그 핀만** 후보로 삼는다(MEMORY는 이미 다녀온 장소이므로). 사용자가 명시적으로 "전체"를 선택하면 MEMORY 포함.

## 안 하면 어떻게 되는가

- 핀 수가 많아질수록 사용자가 매번 직접 스크롤/검색해서 선택 → 누적된 자산 활용도 떨어짐
- "데이트 결정 부담 감소"라는 차별점 소실

## 사용자와 규모

- ~100명. 룰렛 사용 빈도 추정: 인당 주 1~2회
- 평균 그룹 핀 50개 → 1km 반경 PLACE 핀은 평균 3~5개 예상

## 성공 기준

- 위치 권한 허용 후 추천 결과 표시까지 ≤ 1.5초
- 범위 내 후보 0건일 때 안내 + 다음 범위로의 확장 유도 100% 동작
- 같은 사용자가 5회 연속 룰렛 시 동일 핀 추천 비율 ≤ 20% (랜덤성 보장)
