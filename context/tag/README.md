# tag

핀의 카테고리. **MVP 핵심 기능**으로 PLACE / MEMORY 2종을 제공한다. 지도에서 파스텔톤 점으로 시각화된다.

## 배경

서비스의 컨셉이 단순 "데이트 장소 지도"에서 "**장소 공유 + 추억 공유**" 사이트로 확장되면서, 핀의 의미를 두 카테고리로 구분해야 한다.

- **PLACE 태그 (파란 동그라미 파스텔)**: "가고 싶은 장소". 인스타 릴스에서 발견한 곳, 가보고 싶은 곳
- **MEMORY 태그 (핑크 하트 파스텔)**: "추억의 장소". 연인이나 그룹원과 다녀온 의미 있는 장소

핀 등록 경로에 따라 기본값이 다르며, 메모는 모든 태그에서 추가/수정 가능하다. PRD §3-B의 `visited` UI는 본 도메인 도입과 함께 **제거**되었다.

## 안 하면 어떻게 되는가

- 서비스가 단순 "장소 컬렉션"에 머무름 → "추억 공유" 차별점 소실
- 지도가 시각적으로 단조로워져 사용자가 핀 간 의미를 구분 못 함

## 사용자와 규모

- 모든 MVP 사용자가 사용 (~100명, 핀당 1태그 강제)
- PLACE / MEMORY 비율 추정: 챗봇 자동 등록 비중이 높아 PLACE 70% / MEMORY 30% 예상

## 성공 기준

- 챗봇 자동 등록 시 PLACE 기본값 정확도 100%
- 웹 직접 등록 시 사용자 선택 UI 표시 (선택 후 등록까지 ≤ 3 클릭)
- 지도에서 PLACE/MEMORY 시각 구분 즉시 인지 가능 (UX 테스트 기준)
