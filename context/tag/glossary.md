# tag 용어 사전

| 용어 | 설명 |
|------|------|
| Tag | 핀의 카테고리. MVP에서는 enum 컬럼(`pins.tag`)으로 구현. 핀당 1개 강제 (NOT NULL) |
| PLACE | "가고 싶은 장소" 태그. 시각: 파란 동그라미 파스텔. 챗봇 자동 등록 시 기본값 |
| MEMORY | "추억의 장소" 태그. 시각: 핑크 하트 파스텔. 웹에서 사용자가 명시적으로 선택 |
| 자동 기본값 | 챗봇(릴스 공유) 경로로 등록되는 핀은 무조건 PLACE |
| 사용자 선택 | 웹 검색/직접 추가 경로에서 사용자가 PLACE / MEMORY 중 1개 선택 |
| 파스텔톤 점 | 지도 마커의 기본 표현. 태그에 따라 색상/형태 결정 |
| ~~visited~~ | **제거됨**. 방문/미방문 구분은 더 이상 없음 |
