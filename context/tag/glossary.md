# tag 용어 사전

| 용어 | 설명 |
|------|------|
| Tag | 핀의 카테고리. MVP에서는 enum 컬럼(`pins.tag`)으로 구현. 핀당 1개 강제 (NOT NULL). V006 이후 `REEL/WISH/MEMORY` 3종 |
| REEL | "발견" 태그. 시각: 연보라 `#C5B4E3` 인스타그램 아이콘. **카카오톡 챗봇 경로로 등록된 핀 (자동 추출 + 후보 카드 선택 둘 다 포함)**. 챗봇 자동 등록 시 기본값 |
| WISH | "설렘" 태그. 시각: 민트 `#A8E6CF` 동그라미. 웹에서 사용자가 "가보고 싶은 곳"으로 명시적 저장 |
| MEMORY | "추억" 태그. 시각: 핑크 `#FFB3C6` 하트. 웹에서 사용자가 "다녀온 의미 있는 곳"으로 명시적 저장 |
| 자동 기본값 | 챗봇(릴스 공유) 경로로 등록되는 핀은 무조건 REEL |
| 사용자 선택 (웹 등록) | 웹 등록 경로에서 사용자가 WISH / MEMORY 중 1개 선택. **REEL은 챗봇 전용 권장 태그로 웹 신규 등록 UI에서는 노출하지 않음** |
| 사용자 선택 (편집) | 핀 편집 다이얼로그(`PinEditDialog`)와 지도 팝업에서는 REEL/WISH/MEMORY 3종 모두 선택 가능. 잘못 저장된 태그를 자유 수정 |
| REEL 정책 (D3) | REEL은 정책상 챗봇 전용 권장이지만 **백엔드 API가 강제하지 않음** (enum 검증만). 웹 UI 차원의 제한만 유지. 정책 vs 검증의 단순성 우선 |
| 파스텔톤 점 | 지도 마커의 기본 표현. 태그에 따라 색상/형태 결정 (REEL=연보라 인스타 아이콘, WISH=민트 원, MEMORY=핑크 하트) |
| ~~PLACE~~ | **V006 마이그레이션으로 제거됨**. 기존 PLACE 핀은 모두 REEL로 일괄 변환 |
| ~~visited~~ | **제거됨**. 방문/미방문 구분은 더 이상 없음 |
