# group

핀/메모/태그를 공유하는 사용자 묶음. MVP는 2인 커플, 향후 N인 그룹으로 확장 가능한 구조로 설계한다.

## 배경

서비스의 핵심 가치는 "우리만의 공유 지도"다. 따라서 핀 데이터는 개인이 아니라 **그룹** 단위로 묶인다. MVP는 정확히 2명(커플)만 허용하지만, 추후 친구/동호회/가족 등 N인 그룹으로 자연스럽게 확장될 수 있도록 처음부터 `Group`-`GroupMember` 구조로 설계한다. 즉 `Couple_ID`라는 이름 대신 `group_id`를 쓰고, 비즈니스 규칙(`group.size == 2` 제약)만 MVP에 추가한다.

## 안 하면 어떻게 되는가

- 데이터 격리/공유 불가 → 핀이 등록한 본인에게만 보이거나 모두에게 보임. 핵심 가치 소실
- 추후 N인 확장 시 도메인 리네이밍/마이그레이션 비용 발생

## 사용자와 규모

- MVP: ~50 그룹 (= ~50쌍 = ~100명)
- 그룹당 평균 멤버: 2명 (MVP 강제), 추후 평균 3~5명 예상

## 성공 기준

- 초대 링크 발급 → 파트너 수락 → 매칭 완료까지 ≤ 1분
- 초대 링크 24시간 만료 정확히 적용
- 1인 1그룹 제약(MVP) 위반 0건
