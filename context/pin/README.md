# pin

그룹별 장소 핀 CRUD 핵심 도메인. **visited(방문 인증) 기능 없음** — 핀의 의미 구분은 `tag`로 처리.

## 배경

핀은 서비스의 가장 작은 의미 단위다. 한 핀은 (장소명 + 좌표 + 태그 + 메모 + 원본 URL)을 가지며 특정 [[group]]에 귀속된다. 동일 그룹 내에서 같은 인스타 URL의 중복 등록을 막아야 한다. PRD 원문의 "visited(방문 인증)" 정책은 QA를 통해 제거되었고, 대신 [[tag]] 도메인(`PLACE` / `MEMORY`)으로 핀 의미를 표현한다.

## 안 하면 어떻게 되는가

- 서비스 자체가 성립하지 않음 (핀이 도메인 핵심 엔티티)
- 중복 방지가 없으면 동일 장소가 여러 번 저장되어 지도가 지저분해지고 사용자가 혼란

## 사용자와 규모

- MVP: ~50 그룹 × 평균 50핀/그룹 → 약 2,500핀 1차 누적
- 1년 후 추정: 그룹당 ~200핀 (이론상 ~10k핀, Supabase 무료 티어 내 충분)

## 성공 기준

- 핀 등록 → 지도 표시까지 ≤ 2초
- 동일 그룹 내 중복 등록률 = 0%
- 챗봇 자동 등록 시 `tag=PLACE` 기본값 적용 정확도 = 100%
