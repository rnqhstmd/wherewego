# Phase 10 — 장소 방문 감지 ("이 장소에 오셨나요?")

## 개요

사용자가 **WISH·REEL** 태그로 저장해둔 핀 좌표 100m 이내에 실제로 도착하면,
지도 화면에서 바텀 토스트를 띄워 추억(MEMORY)으로 전환을 유도한다.

> MEMORY 태그 핀은 이미 다녀온 장소이므로 감지 대상에서 제외한다.

---

## 트리거 조건

| 조건 | 값 |
|------|-----|
| 대상 핀 태그 | WISH, REEL (MEMORY 제외) |
| 감지 반경 | 100m (Haversine, 프론트 계산) |
| 감지 시점 | 지도 화면 활성 + GeolocateControl 위치 갱신 시 |
| 중복 표시 방지 | 세션 중 동일 pinId 팝업은 1회만 표시 (Set으로 관리) |
| 동시 감지 | 가장 가까운 핀 1개만 표시 |

---

## 화면 플로우

```
GPS 위치 갱신
    ↓
WISH/REEL 핀과 거리 비교
    ↓
100m 이내 핀 발견 + 미표시 세션
    ↓
[바텀 토스트] "온량 근처에 계신가요?"
    ├── "다음에 올게요" → 팝업 닫힘, 세션 중 재표시 없음
    └── "네, 다녀왔어요 →"
            ↓
        태그 MEMORY로 변경 (PATCH /pins/{id})
            ↓
        마커 전환 애니메이션
        (♡ 아웃라인 → ● 채워진 핑크, scale up/down)
            ↓
        메모 바텀시트 슬라이드 업
        "이 순간을 기록해볼까요?" + 텍스트 입력
            ├── [건너뛰기] → 시트 닫힘
            └── [저장] → 메모 저장 (PATCH /pins/{id}) + 시트 닫힘
```

---

## 화면 사양

### 바텀 토스트

```
┌─────────────────────────────────────┐
│  📍 온량 근처에 계신가요?            │
│     서울 송파구 백제고분로43길        │
│                                     │
│  [다음에 올게요]   [네, 다녀왔어요 →] │
└─────────────────────────────────────┘
```

- 지도 화면 하단에서 슬라이드 업 (translateY 애니메이션)
- 배경: `colors.panel`, 라운드 16px, 그림자
- CTA 버튼: 핑크(`colors.cta`) / 보조 버튼: 회색 텍스트

### 마커 전환 애니메이션

- WISH/REEL 마커 → scale(1.4) → scale(1.0) → MEMORY 마커로 교체
- 전환 시간: 400ms ease-in-out
- 옵션: 잔물결(ripple) 효과 1회

### 메모 바텀시트

```
┌─────────────────────────────────────┐
│  ← 건너뛰기                  저장   │
├─────────────────────────────────────┤
│  ✓  온량, 다녀왔어요!               │
│     2026년 5월 23일                 │
│  ─────────────────────────────────  │
│  이 순간을 기록해볼까요?             │
│  ┌─────────────────────────────┐   │
│  │ 오늘의 기억을 남겨보세요...  │   │
│  └─────────────────────────────┘   │
└─────────────────────────────────────┘
```

## 구현 범위

### 프론트엔드

| 작업 | 파일 |
|------|------|
| GPS 위치 갱신 시 근접 핀 감지 훅 | `_hooks/useVisitDetection.ts` (신규) |
| 세션 중 표시된 pinId Set 관리 | `useVisitDetection` 내부 |
| 바텀 토스트 컴포넌트 | `_components/VisitToast.tsx` (신규) |
| 마커 전환 애니메이션 | `MapboxView.tsx` 내 마커 교체 로직 |
| 메모 바텀시트 | `_components/VisitMemoSheet.tsx` (신규) |
| MapClient 연결 | `MapClient.tsx` — 훅 연결 + 토스트/시트 조건부 렌더 |

### 백엔드

- 신규 API 없음
- 기존 `PATCH /api/v1/groups/{groupId}/pins/{pinId}` (tag 변경) 재사용
- 기존 `PATCH /api/v1/groups/{groupId}/pins/{pinId}` (memo 변경) 재사용

## 엣지케이스

| 상황 | 처리 |
|------|------|
| GPS 실내 오차 | 사용자가 직접 확인하는 구조 — 문제 없음 |

| 이미 MEMORY인 핀 | 감지 대상 제외 |
