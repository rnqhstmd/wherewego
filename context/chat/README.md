# chat

그룹원 간 단체 채팅 + 인스타 릴스 링크 공유·장소 등록을 담당하는 도메인. 기존 봇 티키타카(모아보기, [[chatbot]] 인앱 봇 채팅)를 **그룹 채팅방** 개념으로 대체한다.

## 배경

기존 모아보기는 "사용자 ↔ 봇" 1:1 대화로만 릴스 장소를 저장할 수 있었다 — 그룹원끼리 대화할 수 없고, 봇 응답을 기다리는 티키타카가 강제됐다. 이를 그룹 채팅방으로 전환한다:

1. 평소엔 그룹원끼리 자유롭게 채팅한다.
2. 인스타그램에서 릴스를 보다가 "우리 앱에 보내기"(ShareExtension)를 누르면 릴스 링크가 그룹 채팅방에 메시지로 쌓인다.
3. **보낸 사람**이 앱에서 그 메시지 하단의 「장소 등록하기」 버튼을 누르면 팝업에서 장소 추출이 시작되고, 추출된 장소 중 꼭 가보고 싶은 곳을 체크(=WISH)하면 나머지는 발견핀(REEL)으로 함께 저장된다.
4. 등록이 완료되면 그 메시지의 버튼이 **모든 그룹원에게** 「장소가 등록되었어요. 구경하실래요?」로 바뀌고, 누르면 해당 그룹 지도로 전환되어 그 릴스로 저장된 핀만 필터링되어 보인다.
5. 다른 그룹원은 등록 전까지 「장소 등록전이에요」 비활성 버튼을 본다.

## 안 하면 어떻게 되는가

- 그룹원 간 소통 채널이 앱 밖(카카오톡 등)에 머물러 릴스 공유 → 핀 저장 흐름이 끊긴다
- 봇 티키타카 강제 — 링크를 보내는 즉시 추출이 돌아 사용자가 원하는 시점에 정리할 수 없다
- 상대방은 릴스가 공유됐는지, 장소가 등록됐는지 알 수 없다

## 사용자와 규모

- 사용자: 베타 ~수십 명, 그룹당 2~4명
- 트래픽 추정: 그룹당 일 수십 건 채팅 + 주 5~10건 릴스 공유

## 성공 기준

- 릴스 공유 → 채팅방 노출까지 즉시(전송 API 1회)
- 장소 추출 성공률 기존(봇) 대비 동등 이상 — 팝업 UX 덕에 deadline 완화(카카오 5초 SLA 해제) 가능
- 버튼 상태(등록전/등록됨) 불일치 0건 — 파생 상태 설계로 드리프트 원천 차단
- 그룹원 채팅 수신 지연: 포그라운드 수 초 내(APNs 트리거 재조회)
