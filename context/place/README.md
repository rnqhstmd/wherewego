# place

외부 장소 API(카카오 로컬, Google Places)와 인스타 메타 파싱을 담당하는 어댑터 도메인.

## 배경

핀을 만들려면 (1) 인스타 릴스 캡션에서 장소명을 추출하고 (2) 외부 API로 좌표/주소를 받아와야 한다. 이 두 단계가 모두 외부 의존이며 실패 가능성이 높으므로, 별도 도메인으로 분리하여 어댑터/리트라이/폴백 정책을 격리한다. 핵심 핀 도메인([[pin]])은 이 도메인이 반환한 정형 결과(`place_name`, `address`, `lat`, `lng`)만 받는다.

## 안 하면 어떻게 되는가

- 사용자가 모든 장소 정보를 수동 입력해야 함 → 챗봇 자동화 가치 소실
- API 폴백/리트라이 정책이 핀 도메인과 섞이면 책임 분리가 무너지고 유지보수 어려움

## 사용자와 규모

- 트래픽: 일 평균 ~100건 인스타 링크 수신 → 카카오 로컬 호출 ~100건 + Google Places 폴백 ~30건(해외 추정 30%)
- 카카오 로컬 무료 한도: 300k건/일 (충분)
- Google Places: $200 무료 크레딧/월 (약 12k 검색 가능)

## 성공 기준

- 인스타 캡션에서 장소명 추출 성공률 ≥ 70%
- 카카오 → Google 폴백 자동 전환 정확도 ≥ 95% (국내 장소가 Google로 가지 않을 것)
- 외부 API 평균 응답 ≤ 1.5초
