# memo

핀에 부가되는 메모. 챗봇 메시지의 2초 룰 자동 매칭과 수동 수정 정책을 담당.

## 배경

서비스의 감성적 가치는 "단순 정보가 아니라 우리가 왜 이곳을 가고 싶어 했는지의 기억"이다. 인스타 공유와 함께 카카오톡에 던진 한 줄 메시지("여기 디저트 맛있대")가 자연스럽게 핀의 메모가 되도록 2초 룰을 적용한다. 메모는 핀의 컬럼이지만 정책 복잡도가 높아(2초 룰, 우선순위, 수동 덮어쓰기) 별도 도메인으로 분리한다.

## 안 하면 어떻게 되는가

- 메모 자동화가 없으면 감성 가치 소실 → 그저 좌표 컬렉션이 됨
- 우선순위 정책이 없으면 자동 메모와 수동 수정이 충돌

## 사용자와 규모

- 핀당 메모 1건 (1:1, 다중 메모 미지원)
- 트래픽: 핀 등록량과 동일 수준(~100건/일)

## 성공 기준

- 2초 룰 매칭 정확도 ≥ 95% (링크→텍스트 순서일 때 자동 저장 성공)
- 수동 수정 즉시 반영
- 자동 메모 덮어쓰기 정책 명확히 정의됨
