# 🗺️ 서비스 기획서: 우리가갈지도 (wherewego) 
**"우리가 함께 갈지도, 우리가 만든 지도"**

---

## 1. 서비스 개요 (Product Vision)
* **슬로건:** 인스타 릴스 한 줄이면 완성되는 우리만의 글로벌 데이트 지도
* **핵심 가치:** 1. **편리함:** 카톡 전송 한 번으로 장소명, 좌표, 릴스 링크, 메모 자동 저장.
    2. **글로벌:** 전 세계 어디든 3D 지구본 위에 우리만의 핀을 박제.
    3. **감성:** 단순 정보가 아닌, 우리가 왜 이곳을 가고 싶어 했는지 '기억'을 기록.
* **타겟:** 릴스를 공유하며 데이트 장소를 정하는 모든 글로벌 여행/데이트 커플.

---

## 2. 핵심 유저 플로우 (Main User Journey)

1.  **웹 접속:** 카카오 로그인 후 파트너에게 초대 링크 발송하여 **커플 매칭**.
2.  **연동:** 웹에서 발급된 **5자리 연동 코드**를 카카오톡 챗봇에게 전송 (최초 1회).
3.  **수집:** 인스타 릴스 공유하기 시 **메시지와 함께** 챗봇에게 링크 전송.
4.  **확인:** 챗봇이 "핀 꽂기 완료" 알림을 주면, 웹 지도에서 3D로 확인.
5.  **활동:** 데이트 당일 **룰렛**을 돌려 장소를 정하고, 다녀온 뒤 **방문 인증**.

---

## 3. 상세 기능 명세 (Detailed Features)

### A. 카카오톡 챗봇 (수집 및 연동 모듈)
* **최초 연동:** 5자리 난수 코드를 인식하여 `botUserKey`와 유저 계정을 1:1 매칭.
* **데이터 파싱 (장소명 추출 파이프라인):**
    1. 인스타 링크 수신 시 HTML 메타 스크래핑으로 캡션 전체 수집 (`og:title`, `og:description`).
    2. 캡션에서 regex로 장소명 탐색: `📍` 이모지 뒤 텍스트 → 위치/장소 키워드 → 해시태그 순으로 우선 추출.
    3. 장소명 추출 성공 시 → **카카오 로컬 API** (국내) 또는 **Google Places API** (해외 폴백) 로 좌표 검색.
    4. 장소명 추출 실패 시 → 챗봇이 "어느 곳인가요?" 메시지로 사용자에게 직접 입력 요청.
* **장소 검색 결과 분기:**
    * 검색 결과 1건 → 자동 핀 등록.
    * 검색 결과 복수 → 카카오톡 리스트 카드(최대 5개)로 선택지 제공 후 사용자가 탭하여 확정.
* **국내/해외 장소 API 분기:**
    * 카카오 로컬 API 검색 결과 있음 → 국내 장소로 확정, 좌표 사용 (무료).
    * 카카오 로컬 API 결과 없음 → Google Places API (`language=ko`) 호출 → 한국어 상호명 + 한국어 주소 반환.
* **지능형 메모 매칭:** 링크와 메시지가 연속으로 올 경우(2초 이내), 메시지를 해당 장소의 메모로 자동 저장.

### B. 웹 서비스 (글로벌 3D 지도 및 관리)
* **Global 3D Map:** Mapbox 기반의 전 세계 지도. 줌 아웃 시 3D 지구본 모드 전환.
* **감성 마커 & 팝업:**
    * **핀 UI:** 미방문(아이콘), 방문완료(하트/사진) 상태 구분.
    * **정보창(AMOU 스타일):** 가게 이름, 작성된 메모, 원본 릴스 바로가기 버튼, 방문 체크 버튼.
* **장소 검색 (Search & Add):** 커스텀 검색 UI (Tailwind CSS)로 구현. 카카오/Google API는 백단에서 데이터 소스로만 사용하며, 눈에 보이는 UI는 우리 고유 디자인.
    * 검색어 입력 → Spring Boot → 카카오/Google API → 결과 JSON 반환 → 커스텀 드롭다운 표시 → 선택 시 Mapbox에 핀 추가.
    * Mapbox 핀 표시에 필요한 값: **위도(latitude) + 경도(longitude)** 2개만 사용.
        * 카카오 응답: `x`(경도), `y`(위도)
        * Google 응답: `geometry.location.lat`(위도), `geometry.location.lng`(경도)
* **오늘 어디 갈까? (위치 기반 랜덤 추천):**
    * 진입 시 브라우저 위치 권한 허용 요청.
    * 허용 시 현재 위치 기준 반경 내 미방문 핀 중 랜덤 1곳 추천.
    * 거리 범위 선택 가능: 1km(도보) / 5km(대중교통) / 10km(드라이브).
    * 해당 범위 내 핀이 없을 경우 "근처에 저장된 장소가 없어요" 안내 후 범위 확장 유도.
    * 추천 결과 카드에 장소명, 거리, 메모 표시 후 지도에서 해당 핀으로 이동.
* **메모 관리:** 챗봇으로 자동 등록된 메모 수정 및 신규 메모 입력 기능.

### C. 핀 데이터 구조 (DB 저장 항목)
| 컬럼 | 출처 | 설명 |
|------|------|------|
| `place_name` | API 응답 | 상호명 (한국어) |
| `address` | API 응답 | 주소 (한국어 포맷) |
| `latitude` | 카카오 `y` / Google `lat` | 위도 |
| `longitude` | 카카오 `x` / Google `lng` | 경도 |
| `instagram_url` | 챗봇 수신 링크 | 원본 릴스 URL |
| `memo` | 챗봇 2초 룰 텍스트 | 장소 메모 |
| `visited` | 방문 인증 시 true | 방문 여부 |

> 위경도를 DB에 저장해두면 웹 접속 시 Supabase에서 불러와 Mapbox에 바로 핀을 뿌리는 구조. 지도 API 재호출 불필요.

## 4. 비즈니스 및 운영 정책 (Business Policies)

### A. 가입 및 커플 정책
* **1:1 매칭:** 한 유저는 오직 하나의 `Couple_ID`에만 소속 가능.
* **초대 링크:** 초대 링크는 발급 후 24시간 동안 유효하며, 파트너 수락 시 즉시 매칭.
* **연결 해제:** 커플 해제 시 관계 데이터는 삭제되나, 각자가 등록한 핀 데이터는 개인 계정에 유지 (Private 데이터화).

### B. 데이터 저장 및 메모 정책
* **메모 우선순위:** 1. 인스타 공유 시 동시 입력한 메시지 (자동).
    2. 웹 지도에서 직접 수정한 내용 (수동).
* **2초 룰:** 챗봇에 링크가 들어온 후 2초 이내에 들어온 텍스트만 해당 장소의 메모로 인정. 이후의 대화는 메모로 인식하지 않음.
* **중복 방지:** 동일한 릴스 URL이 동일 커플 내에 존재할 경우 추가 저장 없이 기존 핀 위치로 지도 이동.

## 5. 기술 스택 아키텍처 (Tech Stack)

* **Frontend:** Next.js (App Router), Tailwind CSS, Framer Motion → Vercel 배포 (무료)
* **Backend:** Spring Boot (Spring Web + Spring Data JPA + Kakao OAuth2) → AWS EC2 t3.micro (12개월 Free Tier → 이후 ~$8/월)
* **Database:** Supabase PostgreSQL (JDBC/JPA로 연결, Supabase 클라이언트 불필요)
* **Maps:** Mapbox GL JS (3D 지도 렌더링, 무료 50k loads/월)
* **장소 검색:**
    * 카카오 로컬 API — 국내 장소 키워드 검색 (완전 무료, 300k건/일)
    * Google Places Text Search API — 해외 장소 폴백, `language=ko` 적용 (월 $200 무료 크레딧)
* **Instagram 수집:** HTML 메타 스크래핑 자체 구현 — Spring Boot에서 처리 (`og:description` 캡션 파싱 + regex)
* **Interface:** 카카오 i 오픈빌더 (Skill Webhook → Spring Boot REST API 연동, 리스트 카드 활용)

```
[카카오톡 챗봇] ──Webhook──▶ [Spring Boot / EC2]
                                      │
                           ┌──────────┴──────────┐
                      카카오 로컬 API        Google Places API
                                      │
                                Supabase (PostgreSQL)
                                      │
[Next.js / Vercel] ◀─────REST API─────┘
```

> **제거된 항목:** ~~Apify (Instagram Scraper)~~, ~~OpenAI GPT-4o-mini/vision~~, ~~Vercel Serverless Functions~~
> → AI 없이 regex 파싱으로 대체, Spring Boot 단일 백엔드로 통일, 초기 운영 비용 $0 구조 달성

## 6. 개발 마일스톤 (4주 Sprint)

* **1주차:** Supabase DB 설계 및 Spring Boot 프로젝트 세팅 + 카카오 OAuth2 로그인/커플 매칭 로직 구현, AWS EC2 배포 환경 구성.
* **2주차:** 카카오톡 챗봇 Skill Webhook 구축 (HTML 메타 스크래핑 → regex 장소명 추출 → 카카오/Google 좌표 검색 파이프라인) — Spring Boot REST API로 구현.
* **3주차:** Next.js 프론트엔드 구축 — Mapbox 3D 지도, 핀/팝업 UI 디자인 (AMOU 스타일), Spring Boot API 연동.
* **4주차:** 검색/룰렛 기능 추가 및 모바일 웹 최적화, Vercel 배포 후 최종 런칭.
